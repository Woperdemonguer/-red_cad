# 🏭 3_Product — La Fábrica

## 🧑‍💼 ¿Qué es esta carpeta? (Explicación para no técnicos)

> Si `1_Context/` es la **biblioteca** (documentos de referencia) y `2_Blueprint/` es la **sala de arquitectura** (planos), entonces `3_Product/` es la **fábrica** — el lugar donde se construye el producto real que usarán las cooperativas.
>
> Todo el código ejecutable vive aquí. Cuando alguien abre `https://tudominio.com` y ve la plataforma, lo que está viendo es el resultado de todo lo que hay dentro de esta carpeta.

## 🎓 ¿Qué aprenderás aquí?

1. **Qué es un "frontend":** Es la parte de una web app que VES e INTERACCIONAS. Los botones, los formularios, los colores, las animaciones — todo eso es frontend. La parte que NO ves (base de datos, autenticación) es el "backend".

2. **Por qué "frontend" está dentro de "3_Product":** Porque el frontend ES el producto. Los blueprints son planos. El contexto es referencia. Pero el frontend es lo que realmente llega a las manos del usuario.

3. **¿Dónde está el "backend"?** En este proyecto, el backend es **Supabase** — un servicio en la nube que proporciona base de datos, autenticación y almacenamiento sin necesidad de programar un servidor propio. Es como usar Google Drive en vez de montar un servidor de archivos en tu oficina.

## 💡 Concepto clave: ¿Qué es una "Web App"?

Una **web app** (aplicación web) es un programa que se usa desde el navegador (Chrome, Safari, Firefox) sin necesidad de instalar nada. Ejemplos:
- Gmail es una web app para email
- Google Docs es una web app para documentos
- RedCAD Hub es una web app para la red de cooperativas

La diferencia con una página web normal es que una web app es **interactiva**: puedes rellenar formularios, filtrar datos, subir archivos — no solo leer contenido estático.
