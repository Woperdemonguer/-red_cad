# 🧩 Components: Form — Componentes del Formulario de Diagnóstico

> **¿Qué es esta carpeta?**
> Contiene los componentes React específicos del formulario de diagnóstico de 63 preguntas. Estos componentes renderizan los diferentes tipos de preguntas y bloques del formulario.

> 💡 La estructura de preguntas se define en `config/diagnosticForm.js`. Estos componentes solo se encargan de la **visualización** — la lógica de guardado vive en `lib/supabaseService.js` (`formService`).
