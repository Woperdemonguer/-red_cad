# 🧪 Tests: Hooks — Tests de Lógica de Estado

> **¿Qué hay aquí?**
> Tests que verifican los hooks de React — funciones que gestionan el estado y la lógica de la aplicación.

| Archivo | Qué testea | Nº de tests |
|---------|-----------|:-----------:|
| `useAuth.test.js` | Hook de autenticación: login, logout, detección de rol (admin/CAD), manejo de errores | 8 |

> 💡 Los hooks son la "lógica invisible" detrás de la interfaz. `useAuth` controla quién puede ver qué y mantiene la sesión del usuario.
