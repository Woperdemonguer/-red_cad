# 🧪 Tests: Components — Tests de Componentes de UI

> **¿Qué hay aquí?**
> Tests que verifican que los componentes de interfaz (botones, modales, spinners, etc.) se renderizan correctamente y responden a las interacciones del usuario.

| Archivo | Qué testea | Nº de tests |
|---------|-----------|:-----------:|
| `ui.test.jsx` | `LoadingSpinner`, `ConfirmModal`, `ToastProvider` — renderizado, interacciones, estados | 12 |

> 💡 Usamos **Testing Library** para simular cómo un usuario real interactúa con los componentes (clics, texto visible, etc.), no cómo están implementados internamente.
