# 🧪 Tests: Lib — Tests de Utilidades

> **¿Qué hay aquí?**
> Tests que verifican las funciones de utilidad — lógica pura que transforma datos sin interactuar con la base de datos ni la UI.

| Archivo | Qué testea | Nº de tests |
|---------|-----------|:-----------:|
| `formUtils.test.js` | Funciones de cálculo y transformación del formulario de diagnóstico: puntuaciones, promedios, validaciones | 32 |

> 💡 Estas funciones son "matemáticas puras" — dada una entrada, siempre producen la misma salida. Son los tests más fáciles de escribir y los más fiables.
