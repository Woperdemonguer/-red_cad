# 📂 Directory — Directorio de Cooperativas

> **Ruta:** `/directory`
>
> **¿Qué hace esta página?**
> Muestra un listado de todas las cooperativas (CADs) de la red, con búsqueda y filtrado. Cada cooperativa tiene una tarjeta con información resumida y un enlace a su ficha completa.

## Subcarpeta

| Carpeta | Ruta | Propósito |
|---------|------|-----------|
| `[id]/` | `/directory/123` | Ficha individual de un CAD (página dinámica) |

> 💡 `[id]` es una ruta dinámica de Next.js. El valor entre corchetes se captura como parámetro para cargar los datos de esa cooperativa específica.
